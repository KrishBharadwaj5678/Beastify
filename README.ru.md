# 🦁 Beastify

**Beastify** это интерактивный веб-сайт с дополненной реальностью (AR), который позволяет пользователям исследовать и взаимодействовать с 3D-моделями животных в уникальной и захватывающей форме. Проект направлен на создание увлекательного и образовательного опыта за счёт интеграции различных функций, связанных с животными.

![BeastifyDemo](https://github.com/KrishBharadwaj5678/Beastify/raw/main/BeastifyDemo.png)

## ✨ Возможности

| **Функция**                            | **Описание**                                                           |
| -------------------------------------- | ---------------------------------------------------------------------- |
| **🦊 Реалистичные 3D-модели животных** | Исследуйте и взаимодействуйте с детализированными 3D-моделями животных |
| **📚 Подробные факты о животных**      | Узнавайте информацию о различных видах                                 |
| **🎙️ Обучение с голосом**             | Слушайте интересные факты о животных с помощью синтеза речи            |
| **🔊 Реалистичные звуки животных**     | Погружение в природу с рычанием, чириканьем и другими звуками          |
| **📸 Захват изображения**              | Делайте снимки животных в режиме AR                                    |
| **🌍 Дополненная реальность**          | Размещайте и взаимодействуйте с животными в реальном мире              |
| **🏝️ 360° иммерсивные окружения**     | Перенос в джунгли, океаны и саванны                                    |
| **🎮 Увлекательная игра на память**    | Тренируйте память, сопоставляя карточки с животными                    |
