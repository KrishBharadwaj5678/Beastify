# 🦁 Beastify

**Beastify** は、ユーザーがユニークで没入感のある方法で3D動物モデルを探索し、インタラクションできるインタラクティブな拡張現実（AR）ウェブサイトです。このプロジェクトは、動物に関するさまざまな機能を統合することで、魅力的で教育的な体験を提供することを目的としています。

![BeastifyDemo](https://github.com/KrishBharadwaj5678/Beastify/raw/main/BeastifyDemo.png)

## ✨ 機能

| **機能**             | **説明**                  |
| ------------------ | ----------------------- |
| **🦊 リアルな3D動物モデル** | 高精細な3D動物モデルを探索・操作できます   |
| **📚 詳細な動物の知識**    | さまざまな動物の種類について学習できます    |
| **🎙️ 音声学習機能**     | テキスト読み上げ機能で動物の豆知識を音声で再生 |
| **🔊 リアルな動物の音**    | 迫力ある鳴き声や自然音で没入体験        |
| **📸 キャプチャ機能**     | ARモードで動物のスクリーンショットを撮影   |
| **🌍 拡張現実（AR）**    | 現実空間に動物を配置してインタラクション可能  |
| **🏝️ 360°没入環境**   | ジャングル・海・サバンナなどの世界へ移動    |
| **🎮 メモリーゲーム**     | 動物カードを合わせる楽しい記憶ゲーム      |
