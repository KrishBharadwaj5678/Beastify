# 🦁 Beastify

O **Beastify** é um site interativo de Realidade Aumentada (AR) que permite aos usuários explorar e interagir com modelos 3D de animais de forma única e imersiva. Este projeto tem como objetivo proporcionar uma experiência envolvente e educacional, integrando diversas funcionalidades relacionadas aos animais.

![BeastifyDemo](https://github.com/KrishBharadwaj5678/Beastify/raw/main/BeastifyDemo.png)

## ✨ Funcionalidades

| **Funcionalidade**                     | **Descrição**                                                            |
| -------------------------------------- | ------------------------------------------------------------------------ |
| **🦊 Modelos 3D realistas de animais** | Descubra e interaja com modelos 3D detalhados de animais                 |
| **📚 Fatos completos sobre animais**   | Aprenda sobre diferentes espécies                                        |
| **🎙️ Aprendizado com voz**            | Ouça fatos interessantes sobre animais com assistente de texto para fala |
| **🔊 Sons autênticos de animais**      | Imersão na natureza com rugidos, cantos e sons realistas                 |
| **📸 Captura**                         | Tire fotos em AR dos animais em modo de realidade aumentada              |
| **🌍 Realidade Aumentada**             | Posicione e interaja com animais no ambiente real                        |
| **🏝️ Ambientes imersivos em 360°**    | Transporte-se para florestas, oceanos e savanas                          |
| **🎮 Jogo da memória envolvente**      | Treine sua memória combinando cartas de animais                          |
